# 小乌龟

小乌龟 是基于 [FongMi] / CatVod 生态二次开发的 Android 影音应用,保留原有点播、直播、Spider、解析、投屏、本地 HTTP 服务等能力,并重点增强了**多源合并** 、**动漫追番**、**首页导航栏自定义***订阅源安全检测**、**WebHome 自定义首页**、**App Native SDK**、**管理页面**、**远程托管**。
